# Security Policy

The Veyra team takes all security vulnerabilities seriously. Thank you for improving the security of our software.

---

## Supported Versions

Only the latest release of Veyra receives active security updates.

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

---

## Reporting a Vulnerability

If you discover a security vulnerability within Veyra, please report it privately to the system administrator or maintainers rather than opening a public issue.

When submitting a vulnerability report, please include:
- A description of the vulnerability and its potential impact.
- Clear steps to reproduce or a proof of concept.
- Any suggested remediations or patches.

Security advisories will be published upon resolution.
